# VelvetAura
Repo for my fashion website

## Brand

The site's brand name is **Maison Norr**. It appears in the page title, the header logo and the footer.

## Run

It is a static site with nothing to install. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8765
```

Then visit http://localhost:8765.

## Test

Needs Node.js 18 or newer. From the repo root:

```
node --test tests/
```
